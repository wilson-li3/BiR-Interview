# Blueprint Application Tracker

Blueprint is a student-run nonprofit at the University of Waterloo that builds software for other nonprofits. Every term, students apply to join us in different roles. Right now we track applications in a spreadsheet, and it's getting messy.

**Your task:** build a small application tracker.

## What's here

```
src/
  types.ts    # Basic definitions (Applicant, Application, Role, etc.)
  data.ts     # A few sample applications to get you started
  tracker.ts  # An ApplicationTracker class with empty methods
  index.ts    # Entry point — try things out here
```

All of this is a starting point, not a spec. Feel free to change, rename, or delete anything.

## Requirements

At minimum, it should be possible to:

1. Add a new application
2. List or view applications
3. Change an application's status (e.g. move someone from "applied" to "interviewing")

## Make it your own

Past that, you decide. Some ideas, which are **not** required:

- Filter or search (by role, program, year, status...)
- Some summary stats (e.g. how many applicants per role)
- Validation (what counts as a valid application?)
- Saving data so it's still there after a restart
- A CLI, a web UI, or an API
- Tests

You can use any language, framework, or library. If you'd rather start over in Python, Go, React, or something else, go for it.

## What we care about

- Code that is clear and works
- The decisions you make and why
- How you'd extend it later

We value **a few things done well** more than lots of things done halfway.

## Getting started

You'll need [Node.js](https://nodejs.org/) (v18+).

```bash
npm install
npm start
```
